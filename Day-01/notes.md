## DHCP vs Static IP

### DHCP
- Automatically assigns IP addresses
- Reduces manual effort
- Commonly used for client devices
- Easier to manage at scale

### Static IP
- Fixed IP address
- Used for servers and critical infrastructure
- Ensures consistent connectivity
